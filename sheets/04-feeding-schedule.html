How to Use · Feeding Schedule Grid

Seven days, tick-boxes, and a gentle end to “I thought you fed him”.

What this sheet builds

A shared truth on the fridge. When feeding lives on paper, no single person carries it in their head, and the pet gets the same breakfast from whoever reaches the kitchen first.

Sixty-second setup

  1. Copy what you already do today — this grid describes reality first, ambition later.
  2. Write the portions once per column in words you’d say out loud (“half a scoop plus a splash”).
  3. Hang it where the bowls live; tick as fed. A ticked row is a done thing — no memory required.

Kind notes for busy brains

  • The tick-box is the whole trick: it turns feeding from a nagging thought into a finished, visible thing.
  • Meds and extras ride the same row and the same tick — pair this grid with the vet log so dosing never drifts.
  • Missed ticks stay un-judged; missed meals get noticed. That’s the difference the grid exists for.

Fresh water, quietly important

The water tick refills brains too: a rinse-and-refresh rule in the top box keeps it from becoming a once-a-day afterthought. Cats especially prefer a clean, full bowl and will say so loudly.
